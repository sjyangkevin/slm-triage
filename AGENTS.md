# Contribution Guidelines

## Issues

- Clearly describe the problem or feature request.
- Include steps to reproduce for bug reports.
- Reference related issues or discussions when applicable.
- Do NOT open issues that are already covered by existing open issues.

## Pull Requests

- Each PR must reference an existing, approved Issue.
- Keep changes focused — one logical change per PR.
- Include or update tests for any code changes.
- Write a clear title that summarizes the change (e.g., "Fix timeout in retry logic").
- Provide a description explaining *what* changed and *why*.
- Do NOT submit AI-generated code without thorough review and testing.
